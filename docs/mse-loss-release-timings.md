The primary timed loop performs full-output materialization with
`np.asarray(output, dtype=np.float32).copy()` and folds every output bit,

ignored inside the timed loops for both implementations; the focused
differential tests cover warning parity.

each per-cell ratio to `[0.10x, 10.00x]` before geometric aggregation.
