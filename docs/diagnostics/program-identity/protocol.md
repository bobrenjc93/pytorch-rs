## Fixed finite programs and inputs

Programs below are exact semantic fixtures; whitespace/function filenames are recorded in the consumer manifest. Do not substitute a favorable family after a measurement. The six families run in this order, each with small then large input sizes on one compiled callable per family:

1. Affine: `def f(x): return x * 1.25 + 0.75`.
2. Trig: `def f(x, y): return (x.sin() + y.cos()).relu()`.
3. Shared arithmetic: initialize `p = x * y`; perform exactly 37 literal-range iterations of `p = p * 0.9375 + x * 0.03125`; return `p`.
4. Row broadcast: `def f(x, y): return x + y`.
5. Structured input/result: `def f(data): x, y = data['pair']; p = x * y; return {'value': (p, p.sin()), 'alias': x}`. This tests two computed results and current-input alias reconstruction, not three independently allocated outputs.
6. Over-cap arithmetic: initialize `p = x * y`; perform exactly 320 literal-range iterations of `p = p * x + y`; return `p`. Its retained actual instruction count must establish the structural fallback; if it does not exceed the frozen cap, stop and report a fixture-precondition error rather than silently changing the loop count after measurements.

Ordinary one/two-input vector shapes are `(257,)` and `(65537,)`. Row-broadcast shapes are `(37, 7)` with `(7,)`, then `(9363, 7)` with `(7,)`. All data are contiguous CUDA float32, gradients disabled. For element index `i` and phase `p`, x values are `(((i + p) % 29) - 14) / 64`; y values use `(((i + 3*p + 5) % 31) - 15) / 64`. These are exactly representable and generated on the host identically for both frameworks. Scalar runtime values, NaN/Inf/signed-zero edge cases, offsets, dead inputs and other admission controls remain required native/Python tests; do not attribute those controls to this finite latency matrix.
